# MineHelper

MineHelper is a website that uses a fine-tuned Qwen2.5-Coder-1.5B-Instruct model for Minecraft structure generation

Want to see the model? Head over to the [repo](https://github.com/JayNightmare/MyBuilder) and contribute to making it better!
